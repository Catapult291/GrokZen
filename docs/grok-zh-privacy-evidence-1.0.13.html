grok-zh v1.0.13 隐私验证：三层证据链

非官方简体中文社区版（开源 Fork）· 验证时间 2026-09-05 至 09-06 · 方法与工具全部开源，任何人可复现。核心结论：代码上传 / 遥测外传的路径在编译期即被封死，无法在运行期被任何配置或服务端开关重新打开。

版本适用范围（重要）

  • 本页三层证据链的测试版本为 v1.0.13；线路层抓包及其结论仅代表该版本，后续版本未重跑。
  • 源码层的编译期 privacy 门禁不随版本变化，后续版本可按本页同一方法单独复验。

结论边界（如实声明）

  • 验证范围：v1.0.13 Windows x86_64 GNU 单一版本、单一账号、受控单轮会话。
  • 不构成证明：服务端侧的数据处理 / 删除承诺；二进制与源码逐字节可复现对应；上传客户端实现本身的安全审计。
  • 如实说明：上传客户端代码并未从源码中删除，防护依赖编译期门禁使其不可达——结论是"封死"，而非"移除"。
