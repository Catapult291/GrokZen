# 1.0.0 — 2026-08-07

[English](1.0.0.md)

## 新功能

- Dashboard 行会简要概述智能体在上一回合完成的工作
- 扩展模态窗口按字母顺序分组，并提供可折叠的 Skills 分区
- 从主目录或其他非项目目录启动时，Grok 会跳过项目目录提示
- `/feedback` 会打开专用反馈框，不再进入提示输入模式
- 自动主题检测可在 SSH 和 tmux 内正常工作
- Markdown 表格在窄窗格中会在单元格内重新排版，不再裁切内容
- 权限提示会显示完整脚本；较长的 bash 正文可用 `Ctrl-F` 展开

## Bug 修复

- MCP 工具返回图片时，不再丢失或损坏大型截图
- 沙箱模式下，Grok 可在包含大量 deny-glob 匹配项的大型目录中正常启动
- 快速连续执行“立即发送”时，不再丢失先前排队的消息
- 按 Esc 或停止后，后台任务不会在取消后重新启动模型
- 环境中存在无效 API 密钥时，登录流程不再被跳过
- 审阅计划时仍可使用模型选择器和命令面板
- Tab 和 Esc 在问题、权限及取消回合卡片上的行为保持一致
- 从 dashboard 执行 `/new` 后，空提示会返回 dashboard
- 在大型或浅克隆 git 仓库中恢复代码库时不再卡住
- 远程恢复默认只恢复对话；仅传入 `--restore-code` 时恢复代码
- 使用鼠标复制 CJK 文本时，会包含选择区域边缘的所有字符
- API 错误会显示为整洁的横幅，不再直接输出原始 JSON
- 在 dashboard 输入 exit 或 quit 会退出 CLI
- 恢复会话或切换模式后，模式指示器（plan/agent/ask）会保持同步
- 删除从 dashboard 打开的会话后，`/delete` 会返回 dashboard
- 在斜杠命令菜单中按 Enter 会执行高亮命令
- 服务中断期间，Grok 会重试更多类型的服务器错误
- 在 dashboard 使用仅适用于会话的斜杠命令时，会显示说明消息
- 等待子智能体时，排队的提示仍然可见，并且可以调整斜杠命令行和图片行的顺序
- 自动回顾不再在回合进行中或忙碌时出现
- `/btw` 错误消息会完整换行显示

## 性能

- Fork 超大型会话时，不再占用会话文件大小数倍的内存
- 即使网络较慢，退出空会话也能立即完成
