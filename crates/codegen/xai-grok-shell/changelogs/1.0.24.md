# 1.0.24 — 2026-10-20

## Community

- Ships prompt-prefix cache guards, side-channel bypass migration and Windows/test hardening on top of 1.0.23; the full test suite is green again.
- Privacy hardening is fully retained: telemetry and research uploads stay compile-time disabled; the update source still points at this repository.

## Features

- **Prompt-prefix cache guards** — frozen system head after compaction, an input[:k] LCP snapshot over 40-round tool loops, and cold-cache warnings on in-session upgrades keep long sessions on a warm prompt prefix.
- **Side-channel bypass model** — title refresh plus flush / dream / suggest / turn-summary requests now run on cline-pass/deepseek-v4.1-flash instead of occupying the main turn.
- **Cold-cache observability** — turn usage tokens are weighted into telemetry, and cache-miss signals surface in spans and product rows.

## Bug Fixes

- **Windows file and path hardening** — file locks no longer race with os error 33, Unix path assumptions are removed from Windows code paths, and path separator/encoding failures are fixed.
- **Test-suite isolation** — local environment leaks, privacy-build upload gates, telemetry assertions and resource sampling now hold under CI; the full suite is back to zero failures.
- **Monitor and session behavior** — identical heartbeats no longer re-wake the monitor, and regressions in session behavior, runtime/config switches and out-of-band compaction interference are fixed.
