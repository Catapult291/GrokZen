# 1.0.26 — 2026-10-27

## 中文社区版改进

- 集成 Astrolabe 原生内容搜索，并移除内置 grep / shell grep，代码检索统一走 search_code。
- 与 x.ai 脱钩：停用账号登录通道与内置 Grok 模型，启动不再强制跳转 auth.x.ai。
- 隐私加固完整保留：遥测与研究数据上传保持编译期关闭，更新源仍指向本仓库。

## 新功能

- **Astrolabe 原生内容搜索** —— 新增 `search_code` / `find_symbol` / `resolve_context` 等 7 个代码检索工具，支持进程内索引、gitignore 尊重与 LSP 语言信息。
- **技能路由 harness** —— listing 分层保留 role，条件激活输出吸收提示；修复中文吸收提示与启动列表误触发。

## Bug 修复

- **内容搜索收敛** —— 移除内置 grep 与 shell grep；`run_terminal_command` 在执行前拒绝 grep/rg 等命令位并指向 search_code。
- **与 x.ai 脱钩** —— 停用账号登录与内置 Grok 模型，启动不再强制跳转 auth.x.ai / accounts.x.ai；模型由 `config.toml` 自行声明。
- **codemode 与工具调用** —— 修复批量授权、序列化边界与嵌套调用 guard；mimo/cline 截断参数区分修复值与模型原始串，错误提示给出换形建议。
