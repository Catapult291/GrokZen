# 1.0.21 — 2026-10-14

## Features

- **Synced with upstream 1.0.45** — one merge absorbs the upstream Chinese fork through `release-v1.0.45` (official monorepo content roughly 1.0.25–1.0.45). Privacy hardening, the Windows adaptations, and the update channel pointing at this repository are kept.
- **Custom agents** from plugins or your config can now be chosen directly with spawn_subagent.
- **MCP servers** can now use a token file that is re-read on every request so rotating credentials stay fresh.
- **Models can now show** a colored notice banner above the prompt while selected.

## Bug Fixes

- **Subagent wait status** now correctly shows "Waiting for N subagents…" when the parent turn is blocked.
- **Permission mode** (auto / always-approve) stays visible when the agent enters plan mode and is restored on exit.
- **Dock sections, queue body, and reveal rows** stay within their documented height rules even on crowded terminals.

## Internal

- **Privacy gates stay closed through the sync** — `TELEMETRY_UPLOADS_ALLOWED=false` remains a compile-time gate; upstream tests that assume shared defaults take an in-test privacy branch instead of loosening the gate.
- **This is an independent community build** — it carries the privacy hardening and the Windows adaptations, and its version number follows this repository's own series.
