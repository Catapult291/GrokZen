# 1.0.21 — 2026-10-14

## 中文社区版改进

- 一次性合并上游社区版至 `release-v1.0.45`，同步官方 monorepo 约 1.0.25–1.0.45 的全部能力。
- 合并后隐私加固完整保留：遥测与研究数据上传保持编译期关闭，更新源仍指向本仓库。
- 对齐上游新增测试与隐私门：凡假定可共享数据的用例改为测试内隐私分支，不放宽 `TELEMETRY_UPLOADS_ALLOWED=false`。
- Windows 适配（GBK 解码、装机脚本、任务栏隐藏等）在冲突解决中按本仓既有决定保留。

## 新功能

- **已并入上游 1.0.45 能力** —— 一次合并吸收上游中文社区版至 `release-v1.0.45`（官方 monorepo 约 1.0.25–1.0.45），同时保留隐私加固、Windows 适配与指向本仓库的更新通道。
- **自定义智能体**可通过 `spawn_subagent` 直接选择（来自插件或配置）。
- **MCP 服务器**支持令牌文件，每次请求重新读取，轮换后的凭据立即生效。
- **模型可显示彩色通知横幅**，选中期间显示在输入框上方。

## Bug 修复

- **子代理等待状态**在父轮次被阻塞时正确显示“正在等待 N 个子代理…”。
- **权限模式**（自动 / 始终批准）进入计划模式时保持可见，退出后恢复。
- **Dock 分区、队列主体与 reveal 行**在拥挤终端下仍遵守文档中的高度规则。

## 内部

- **同步全程隐私门保持关闭** —— `TELEMETRY_UPLOADS_ALLOWED=false` 仍是编译期门；假定可共享默认值的上游测试改走测试内隐私分支，不放宽该门。
- **本版为社区独立构建** —— 包含隐私加固与 Windows 适配，版本号沿用本仓库自身序列。
