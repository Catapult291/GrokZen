# 1.0.28 — 2026-11-13

## Community

- codemode orchestrates MCP tool calls: `search_tool` discovered in the sandbox declares direct-call access on first hit, and multi-step MCP tasks prefer codemode.
- New `[toolset.codemode] default_exposure` setting with direct / deferred / codemode_only / hidden exposure tiers; the compiled-in default tier is now deferred with an exa/tavily preset whitelist.
- A batch of Windows tool-path and test-baseline repairs; warnings cleared across the workspace.

## Features

- **codemode MCP direct calls** — `search_tool` inside the codemode sandbox declares tools for direct invocation on first discovery; routing texts prefer codemode for multi-call MCP tasks.
- **MCP exposure tiers** — MCP tools support direct / deferred / codemode_only / hidden; `[toolset.codemode] default_exposure` (fallback tier `direct|deferred`) is declared, and the compiled-in default is deferred with an exa/tavily preset whitelist.
- **codemode orchestration** — tool description namespace list, inline call budget, and a `detail` parameter on `search_tool`; oversized returns come back as structured digests.

## Bug Fixes

- **Windows tool paths** — normalized model-visible paths across mock LSP servers, web_fetch, grep card lines, read_file echoes, plan-file and task output displays; directory reads classify as IsADirectory; the exported bash schema drops `encoding`/`detach`.
- **pager search blocks** — pattern extraction falls back to a `query` field, aligning with search_code behavior.
- **Test and build baseline** — zero `cargo check` warnings workspace-wide; repaired POSIX/Windows test gates (RUST_MIN_STACK, auth_retry budget, junctioned TEMP directories, gated POSIX-only shell tests).
