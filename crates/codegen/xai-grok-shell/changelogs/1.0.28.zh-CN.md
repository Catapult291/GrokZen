# 1.0.28 — 2026-11-13

## 中文社区版改进

- codemode 可编排 MCP 工具调用：沙箱内 search_tool 首次发现即可声明直调，多步 MCP 任务自动优先走 codemode。
- 新增 `[toolset.codemode] default_exposure` 配置，MCP 工具支持 direct / deferred / codemode_only / hidden 四档暴露；内置默认档位改为 deferred，exa/tavily 预设白名单直通。
- 一批 Windows 工具链路修复与测试基线收口，全仓警告清零。

## 新功能

- **codemode MCP 直调** —— 沙箱内 `search_tool` 首次发现工具即可声明并直调；多步 MCP 任务的路由文案优先选择 codemode。
- **MCP 暴露档位** —— MCP 工具支持 direct / deferred / codemode_only / hidden；声明 `[toolset.codemode] default_exposure` 兜底档位（direct|deferred），内置默认档位为 deferred，exa/tavily 预设白名单直通。
- **codemode 编排补齐** —— 工具描述命名空间清单、inline 调用预算与 `search_tool` detail 参数；超长返回自动换结构化摘要。

## Bug 修复

- **Windows 工具链路** —— mock LSP、web_fetch、grep 卡片路径、read_file 回显、plan 文件与任务输出等模型可见路径统一归一化；目录读取按 IsADirectory 分类；bash 导出 schema 裁剪 encoding/detach 字段。
- **pager 搜索块** —— pattern 提取补 query 字段回落，与 search_code 行为对齐。
- **测试与构建基线** —— 全仓 `cargo check` 警告清零；修复 RUST_MIN_STACK、auth_retry 预算、junction 临时目录等问题，POSIX 专属测试加平台门控。
