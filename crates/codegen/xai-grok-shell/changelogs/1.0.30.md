# 1.0.30 — 2026-11-24

## Features

- **Subagent turn overrides** — subagent turn limits can now be overridden by name and by role, so explore / plan / implementer subagents can run longer or shorter per project.
- **Repetition guard for reasoning** — the text repetition guard now also covers the reasoning channel, stopping looping models from burning tokens on repeated thinking.

## Bug Fixes

- **Session panel history** — the session panel no longer drops sessions older than 30 days.
- **OpenAI-compatible epoch fields** — usage timestamps from OpenAI-compatible upstreams that report floating-point epochs are now parsed correctly.
- **Token number grouping** — session usage token numbers are now grouped in fours for readability.
