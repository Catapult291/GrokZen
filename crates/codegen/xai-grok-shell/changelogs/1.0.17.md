# 1.0.17 — 2026-09-25

## Features

- **`/fork` can branch from an earlier prompt** — choose a point in a picker or pass `--at <prompt>`; the selected prompt is prefilled for rewriting in the child session.
- **`/undo` is now conversation-only** — it uses the rewind picker without a confirmation and leaves files untouched; `/rewind` can restore conversation, files, or both.
- **The session picker supports up to 100 entries** — `/resume` and `F3` hide empty sessions while preserving explicit session selection.
- **Question freeform answers can include pasted images** — images follow their question and reach the model as answer attachments.

## Fixes

- **The compact-mode jump-to-latest indicator owns a row** — the `▼` remains visible after scrolling up instead of being covered by the prompt or overwriting transcript text.

## Internal

- **Windows PTY test support** — ConPTY query handling and case-insensitive environment inheritance keep mock-network tests usable on Windows.
