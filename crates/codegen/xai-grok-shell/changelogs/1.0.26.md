# 1.0.26 — 2026-10-27

## Community

- Ships Astrolabe native content search, removes built-in grep / shell grep, and routes code search through search_code.
- Detached from x.ai: account login and built-in Grok models are disabled; startup no longer force-redirects to auth.x.ai.
- Privacy hardening is fully retained: telemetry and research uploads stay compile-time disabled; the update source still points at this repository.

## Features

- **Astrolabe native content search** — seven new code-retrieval tools (`search_code` / `find_symbol` / `resolve_context` and friends) with in-process indexing, gitignore respect, and LSP language info.
- **Skill routing harness** — names-only listing keeps `role`, conditional activation emits absorption hints; fixed Chinese absorption hint text and false triggers on startup listings.

## Bug Fixes

- **Content search convergence** — built-in grep and shell grep are removed; `run_terminal_command` rejects grep/rg command positions before spawn and points at search_code.
- **Detach from x.ai** — account login and built-in Grok models are disabled; startup no longer force-redirects to auth.x.ai / accounts.x.ai. Declare models in `config.toml`.
- **Codemode and tool calls** — fixed batch authorization, serialization boundaries, and nested-call guards; mimo/cline truncated arguments now distinguish repaired values from the model's raw string, with reshape hints in parse errors.
