## Community

- Fixes production defects in codemode and polishes the /undo picker on top of 1.0.22.
- Privacy hardening is fully retained: telemetry and research uploads stay compile-time disabled; the update source still points at this repository.

- **codemode toolset parity** — grok-build-plan / no_subagents / ask_user toolsets now register codemode; headless and plan sessions can see and call it.
- **codemode template hardening** — the description template no longer interpolates use_tool / search_tool params or by_kind entries, so denying those tools no longer panics rendering (process exit 0xC0000409).
