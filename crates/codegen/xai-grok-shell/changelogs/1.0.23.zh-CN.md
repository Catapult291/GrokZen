# 1.0.23 — 2026-10-18

## 中文社区版改进

- 在 1.0.22（上游 1.0.45）基础上修复 codemode 生产缺陷并打磨 /undo 选择器。
- 隐私加固完整保留：遥测与研究数据上传保持编译期关闭，更新源仍指向本仓库。

## Bug 修复

- **codemode 工具集补齐** —— grok-build-plan / no_subagents / ask_user 三个工具集补注册 codemode；此前全线模型（agentType=grok-build-plan）headless 与 plan 会话里模型看不到也调不了 codemode。
- **codemode 模板防 panic** —— description 模板去掉对 use_tool / search_tool 参数与 by_kind 条目的硬插值，裁剪这两个工具时不再触发渲染 panic（进程 0xC0000409）。
- **/undo 选择器去噪** —— 回退点列表去掉「· N 个文件」后缀；无用户 prompt 预览的合成轮（auto-wake / system-reminder）不再出现，全部被滤空时提示「No undoable prompts」。
