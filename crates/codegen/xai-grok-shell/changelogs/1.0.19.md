# 1.0.19 — 2026-09-29

## Features

- **Detached tasks are labelled in the tasks pane** — a `detach` task, one the user confirmed will outlive its session, now carries a `Detached` suffix on its row, so it is distinguishable from the rows teardown will reap.
- **The tasks pane lists tasks owned by other sessions** — rows fetched with `x.ai/task/list` appear alongside this session's own, each naming the session it belongs to, and can be terminated from the pane. A foreign row shows no view button, since this client holds no scrollback entry or output buffer for it. The list is bounded — running rows oldest-first, finished rows newest-first, capped — so a machine carrying hundreds of durable records still opens quickly.
- **Late completions are delivered to the next session you open** — when a detached task finishes after the session that started it is gone, the completion stays on disk and the next interactive session claims it once, at the start of its first turn, without opening a turn of its own. The note names the task, the session that launched it, how long it ran, when it finished and the log file on disk; the output itself is not inlined, since a task that ran hours ago is usually moot by the time it lands. Completions older than 24 hours are consumed silently.

## Internal

- **Task listing can skip output hydration** — `x.ai/task/list` takes an optional `hydrate` flag. The pane enumerates every durable record with `false`, because reading one output log per task is what makes a full listing slow; the default stays `true`, so existing clients are unaffected.
- **A late completion is claimed atomically** — the delivery marker is a `delivery.json` created with `create_new`, so the in-session completion watcher and the next session's startup scan race for it and exactly one of them delivers.
- **This is an independent community build** — it carries the privacy hardening and the Windows adaptations, and its version number follows this repository's own series.
