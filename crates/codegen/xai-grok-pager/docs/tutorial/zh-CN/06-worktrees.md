# 并行工作：工作树

想让 Grok 在处理某项功能的同时，你（或另一个 Grok 会话）在同一仓库中处理
其他工作吗？**Git worktrees** 为每个会话提供独立的检出目录——互不踩踏修改，
也无需暂存。

## 在工作树中启动会话

- **从任意位置：**按 `Ctrl+N`（按两次确认）新建会话，然后选择工作树选项。
- **从欢迎屏幕：**（在 Git 仓库内）按 `Ctrl+W` 打开“新建工作树”对话框。
- **从 Shell：**

  ```bash
  grok-zh --worktree=my-feature "refactor the auth module"
  ```

  （请使用 `=`——否则提示内容会被当作工作树名称。）

## 这样做的好处

- 在同一仓库上同时运行两到三个 Grok 会话。
- 实验彼此隔离——如果修改效果不理想，主检出目录不会受到影响。
- 工作完成后，可以像处理任何 Git 分支一样将修改应用回来。

**`/fork`** 会将当前对话复制到一个并行会话中——添加指令将其指向具体任务：
`/fork try the async approach`。

要运行多个智能体？**智能体面板**（`/dashboard` 或 `Ctrl+\`）会按状态
显示所有会话——哪些需要输入、哪些正在工作、哪些已经完成。
