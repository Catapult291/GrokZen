# 下一步

你已经掌握了足以高效工作的内容。想了解更多时：

## 内置帮助

- **`/help`** 或 **`Ctrl+P`** — 可搜索所有命令、快捷键和技能。
- **`/docs`** — TUI 中的完整操作指南（在线文档使用 `/docs web`）。涵盖
  会话、无头模式、subagents、sandboxing、memory 以及更多内容。
- **询问 Grok 本身** — 它可以读取自己的用户指南并自行完成设置。
  试试：“我如何在 CI 中运行你？”或“为 GitHub 添加一个 MCP server”。

## 良好习惯

- 会话会自动保存。使用 `grok-zh -c` 恢复最新会话，或使用 `/resume`
  （`Ctrl+S`）选择一个会话。
- 会话太长而变慢？`/compact` 释放上下文；`/context` 显示上下文使用情况。
- 自动化一切：`grok-zh -p "summarize new TODOs" --output-format json`
  以无头模式运行——非常适合脚本和 CI。
- 本社区预览版暂不启用内置更新；请从中文版独立发布渠道获取经过测试的新版本。
- 感觉哪里不对？在官方服务可用时可用 `/feedback` 提交反馈；中文版问题请提交到
  社区 Fork 的问题跟踪器。
