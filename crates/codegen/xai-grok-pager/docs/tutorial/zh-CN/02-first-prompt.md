# 你的第一个提示

Grok Build 就是与一个能够读取代码、运行命令并编辑文件的智能体进行对话——
就在你的终端中。

输入你的需求并按 `Enter`。Grok 会将工作流式输出到提示上方的
**回滚区（scrollback）**：响应、Shell 命令和文件编辑。

## Grok 工作时继续输入

一轮运行期间，`Enter` 会将下一条消息排队，而不是打断当前运行。
改变主意了？在空提示上按 `Enter` 可停止当前一轮，并立即发送排队的消息。

## 始终由你掌控

- **`Esc`** — 立即取消正在运行的一轮（保留草稿）。
- **`Esc Esc`** 空闲时 — 清空提示；提示为空时则打开回退选择器。
  误删了内容？按 `Ctrl+Z` 撤销。
- **`Ctrl+Q`** — 退出（在 VS Code 系列终端中使用 `Ctrl+D`），需按两次。

底部的**快捷键栏**始终显示与你当前操作相关的按键——不确定时，看看底部即可。
