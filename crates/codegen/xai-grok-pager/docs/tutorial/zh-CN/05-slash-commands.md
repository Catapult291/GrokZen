# 斜杠命令

在空提示输入框中输入 `/`，会出现一个可搜索的命令下拉列表。
以下几个命令值得第一天就了解：

| 命令 | 功能 |
|------|------|
| `/help` | 浏览所有命令和键盘快捷键 |
| `/model` | 切换模型或推理强度 |
| `/resume` | 从上次离开的会话继续 |
| `/new` | 开始一个全新会话 |
| `/compact` | 压缩较长的对话以释放上下文空间 |
| `/btw` | 向 Grok 发送旁注，*不中断*当前任务 |
| `/rewind`（别名 `/undo`） | 将文件和历史记录恢复到较早的提示 |
| `/docs` | 在 TUI 或网页中查看完整的操作指南 |
| `/feedback` | 向团队发送反馈 |

其中两个命令值得再仔细看看：

- **`/compact`** 接受可选提示：`/compact keep the auth details`。随时用
  `/context` 检查上下文使用情况——上下文窗口填满时，Grok 也会自动压缩。
- **`/rewind`**（或 **`/undo`**）会恢复每次提示时创建的实际文件快照，
  而不仅仅是聊天记录。

## 命令面板

按 **`Ctrl+P`**（或在回滚区按 `?`）打开命令面板——这里有一个可搜索的列表，
包含所有命令、快捷键和技能。`Ctrl+.` 上还有完整的快捷键速查表
（如果终端吞掉了它，请使用 `Ctrl+X`）。

你无需记住任何内容：`/` 和 `Ctrl+P` 始终会显示当前可用的选项。
