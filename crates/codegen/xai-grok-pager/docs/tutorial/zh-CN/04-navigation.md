# 熟悉界面

屏幕分为三部分：**回滚区（scrollback）**（对话）、下方的
**提示输入框（prompt）**，以及底部的**快捷键栏（shortcuts bar）**。
需要时，待办面板和后台任务面板会滑入界面。

## 焦点

**`Tab`** 在提示输入框和回滚区之间切换焦点。回滚区获得焦点后，
会显示一个选择项，你可以用方向键移动它。

## 在对话中移动

- **`↑`/`↓`** — 选择上一条/下一条记录。
- **`Shift+←`/`Shift+→`** — 在各轮次（你的提示）之间跳转。
- **`PageUp`/`PageDown`** — 按页滚动；可直接在提示输入框中使用，
  无需切换焦点。
- **`←`/`→`** — 折叠/展开选中的记录；较长的工具输出会先收起，
  直到你需要查看为止。
- **`Enter`** — 在全屏查看器中打开选中的记录。

## 面板

- **`Ctrl+T`** — 切换**待办面板（todos pane）**：Grok 为当前任务维护的实时计划。
- **`Ctrl+G`** — 切换**任务面板（tasks pane）**：后台运行的所有内容及其状态。

偏好 vim 键位？**`/vim-mode`** 会将回滚区切换为 `j`/`k`、`g`/`G`
及其他 vim 键位。
